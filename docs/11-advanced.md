# 11. Продвинутое: правка прошивки

Все правки — редактированием [`ballu-oneair-asp-80.yaml`](../ballu-oneair-asp-80.yaml) и [пересборкой](06-firmware.md#своя-сборка). На свой страх и риск: исходник открыт (GPL-3.0), но это устройство с нагревателем — после каждой перепрошивки [следите за нагревом](02-install.md#warnings).

> Быстрый способ понять, как что работает: [загрузите yaml в ИИ-чат и спросите](index.md#самопомощь-как-быстро-находить-ответы).

## Автостарт

По умолчанию после подачи питания всё выключено. Раскомментируйте строку в `on_boot`:

```yaml
esphome:
  on_boot:
    # ...
    - lambda: 'id(fan_output).turn_on().set_speed(30).perform();'
    # Автоматический запуск на 1 скорости после включения
```

## Свои скорости

Кнопки на корпусе переключают скорости 30/65/100 — значения зашиты в lambda бинарного сенсора `touch_1`:

```yaml
# найдите в yaml бинарный сенсор touch_1, блок on_press -> lambda
if (id(fan_output).speed < 30) id(fan_output).turn_on().set_speed(30).perform();
else if (id(fan_output).speed < 65) id(fan_output).turn_on().set_speed(65).perform();
else if (id(fan_output).speed < 100) id(fan_output).turn_on().set_speed(100).perform();
else id(fan_output).turn_on().set_speed(30).perform();
```

Замените 30/65/100 на свои (например, 40/60/80). LED-индикация завязана на те же пороги в скрипте `led_check` — при желании поправьте и её. Ползунок в вебе/HA и так даёт любое значение 0–100 без правок.

## Таймаут раскрутки

Если турбина стартует не с первого раза (успевает остановиться защитой по оборотам), увеличьте `delay: 10s` в блоке `interval: 30s` (повторная проверка оборотов):

```yaml
interval:
  - interval: 30s
    then:
      # ...
      - delay: 10s   # увеличить, например до 20s
```

## <a name="порог-оборотов"></a>Порог оборотов / отключение проверки

Порог защиты — `fan_rpm < 1.0` (в двух местах блока `interval: 30s`). По результатам независимого тестирования (08.2026) защита «не видит» полуживую турбину (например, 50 RPM при нагреве — работает неограниченно долго при почти нулевом потоке). Рекомендация тестировщика — поднять порог до 100 RPM:

```yaml
# было: return id(fan_rpm).state < 1.0;
- lambda: 'return id(fan_rpm).state < 100.0;'
```

Плато 1-й скорости ≈ 536 RPM, штатная раскрутка занимает ~10 с, поэтому порог 100 RPM не мешает нормальному запуску. Более надёжный вариант — сверять обороты с ожидаемыми для установленной скорости.

Полностью **отключить** проверку можно удалив блок `interval` (иногда советуют при ложных срабатываниях) — но вы теряете единственную защиту «вентилятор стоит, а нагрев работает». Поступайте так только осознанно.

## <a name="перенос-датчика"></a>Перенос датчика температуры

Штатный датчик стоит **до** нагревателя (меряет улицу). Пользователи, которым нужна обратная связь по температуре притока, физически переносят NTC за нагреватель (перепечатанная накладка с отверстием или аккуратная переустановка). После переноса:

- датчик показывает температуру выходящего воздуха;
- в центре потока показания выше — подберите смещение фильтром в HA;
- защитная формула нагрева начнёт реагировать на выходную температуру (при +40 °C на датчике нагрев отключается).

## Фикс мгновенного сохранения мощности

Мелкий баг: `on_value` у `heat_power` вызывает `global_preferences->sync()` **до** записи нового значения во flash — при выдёргивании питания в течение минуты может вернуться старое. Лечится задержкой:

> Выявлено и подтверждено независимым экспериментом (тест-отчёт в чате); в репозиторий автора (upstream) правка не отправлялась — в штатной прошивке баг ещё есть. До исправления в upstream действует [«правило одной минуты»](07-controls.md#правило-одной-минуты).

```yaml
number:
  - platform: template
    # ...
    on_value:
      - script.execute: heat_change
      - delay: 10ms        # дать control() сохранить значение
      - lambda: 'global_preferences->sync();'
```

## <a name="ttl"></a>Восстановление через USB-TTL

Если плата не загружается и safe mode недоступен. Понадобится USB-TTL программатор (CH340 и т.п.).

1. Соедините плату с программатором: `rx—rx`, `tx—tx`, `vcc—3.3В`, `gnd—gnd`, `gp0—gnd`.
2. Подключите к компьютеру. На плате загорятся два верхних светодиода (красный и зелёный).
3. Положите палец на **нижний сенсор** — светодиоды погаснут: плата в режиме прошивки.
4. Прошейте бинарник из `bin/` (полный `.bin`, **адрес 0**) через [ESP Download Tools](https://www.espressif.com/en/support/download/other-tools).
5. Отключите `gp0` от земли и перезагрузите плату.

Процедура от автора: [чат](https://t.me/smartintercom/35057). Не справляетесь — напишите автору в личку.

## RGB-светодиод

На плате есть посадочное место под RGB (резисторы не распаяны) — «на морде» корпуса есть отливка, у Xiaomi BioFamily N80 он используется. Завести можно свободными GPIO (в substitutions объявлены `led_1_RGB`…`led_3_RGB`), программная поддержка — на вас.
