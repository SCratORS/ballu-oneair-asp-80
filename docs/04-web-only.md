# 4. Без Home Assistant: веб-интерфейс и кнопки

## Что доступно без Home Assistant

**Коротко:** плата полноценно управляется локальным веб-интерфейсом и сенсорными кнопками — Home Assistant (HA) не обязателен. Но автоматизации, расписания и управление из любой точки, где есть интернет появляются только с HA.

| Способ | Возможности |
|---|---|
| **Кнопки на корпусе** | вкл/выкл вентилятор, скорость по кругу, вкл/выкл нагрев, яркость подсветки |
| **Веб-интерфейс** (по IP платы) | всё то же + ползунок скорости 0–100%, мощность нагрева 10–100%, показания датчиков, обновление прошивки OTA |

Веб-интерфейс доступен сразу после [подключения к Wi-Fi](03-first-run.md), из локальной сети, без интернета и облаков.

## Управление в веб-интерфейсе

- **Скорость вентилятора** задаётся ползунком `oneair_fan` — не только пресеты 30/65/100, а любое значение 0–100%.
- **Нагрев**: переключатель `oneair_heat` (вкл/выкл) + число `oneair_heat_power` (мощность 10–100%, шаг 5).
- Полезный датчик `oneair_heat_current` — фактическая мощность, на которой нагреватель работает прямо сейчас (с учётом защитных ограничений).
- Остальные сущности: температура, обороты (RPM), статус открытия крышки, IP/SSID/MAC, переключатели пищалки и подсветки, кнопка safe mode.

## Кнопки на корпусе

| Кнопка | Короткое нажатие | Долгое нажатие/зажатие |
|---|---|---|
| **Скорость** (вентилятор) | следующая скорость по кругу: 30 → 65 → 100 → 30 | ≈1 с — выключить вентилятор |
| **Нагрев** | включить/выключить нагрев | — |
| **Подсветка (верхняя)** | сбросить ошибку (если мигает) → яркость: выкл → 15% → 100% → выкл | — (в старых прошивках до 13.08.2026 — сброс настроек Wi-Fi; теперь при смене сети плата сама поднимает точку доступа через 1 минуту, если не сможет подключиться к старой Wi-Fi сети) |

Подробная логика и индикация — в [справочнике управления](07-controls.md).

## Чего без Home Assistant НЕТ

- Расписаний («включаться в 8:00») и автоматизаций («по CO₂», «по температуре»)
- Управления из интернета/с телефона за пределами локальной сети
- Алисы и других ассистентов
- Уведомлений

Автор: *«Автоматизации/управление с телефона и прочее — только через ХА. Локально через web интерфейс — только ручное управление»*. Обойти это «умной розеткой» не выйдет: при подаче питания плата не включается сама (безопасность), автостарт включается только [правкой прошивки](11-advanced.md#автостарт).

**Вывод:** если вам нужен только ручной контроль и «тихая ночная скорость» — веб-интерфейса достаточно. Захотели большего — [ставим Home Assistant](05-home-assistant.md).
