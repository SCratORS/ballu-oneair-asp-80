# Глоссарий

Мини-словарь терминов для тех, кто впервые сталкивается с ESP-миром.

| Термин | Что это |
|---|---|
| **ESP32** | Популярный микроконтроллер с Wi-Fi — «мозг» подменной платы |
| **ESPHome** | Открытая система, превращающая yaml-конфигурацию в прошивку для ESP32/ESP8266. Наша плата — ESPHome-устройство |
| **YAML** | Человекочитаемый формат конфигурации (отступы важны!). Вся логика платы — один yaml-файл в репозитории |
| **Home Assistant (HA)** | Открытая система умного дома, работающая на вашем сервере. Не приложение для телефона |
| **Сущность (entity)** | Единица управления/данных в HA: вентилятор, переключатель, датчик… |
| **OTA (Over-The-Air)** | Обновление прошивки «по воздуху», без проводов — через веб-интерфейс платы |
| **Captive portal** | Страница настройки Wi-Fi, открывающаяся при подключении к точке доступа устройства |
| **Точка доступа (AP)** | Режим, когда устройство само раздаёт Wi-Fi для первичной настройки. Пароль нашей платы — `12345678` |
| **Бинарник (.bin)** | Скомпилированная прошивка. `.ota.bin` — для обновления по воздуху, полный `.bin` — для программатора |
| **USB-TTL программатор** | Адаптер для прошивки ESP32 по проводам, когда «по воздуху» уже нельзя |
| **Safe mode** | Режим ожидания прошивки; активируется кнопкой `oneair_safe_mode` |
| **ШИМ (PWM)** | Широтно-импульсная модуляция — способ плавно управлять мощностью (скорость турбины, яркость LED, нагрев) |
| **FG / RPM** | Тахометр турбины: импульсы с вентилятора, которые плата считает и превращает в обороты |
| **PTC** | Керамический нагреватель с саморегуляцией (сопротивление растёт с температурой) |
| **NTC** | Термистор — датчик температуры (сопротивление падает с нагревом) |
| **GPIO** | Выводы микроконтроллера, к которым подключены кнопки, светодиоды, мотор |
| **MAC-суффикс** | Часть аппаратного адреса, добавляемая к имени устройства, чтобы несколько бризеров не конфликтовали |
| **УДЯ (Yandex Smart Home)** | Интеграция Home Assistant ↔ Алиса |
| **mDNS** | Локальные имена вида `имя.local` вместо IP-адресов (работает не на всех роутерах) |
