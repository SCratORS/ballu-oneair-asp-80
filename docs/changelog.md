# История версий прошивки

Составлено по git-истории репозитория и сообщениям автора в [чате](https://t.me/smartintercom). Даты — даты коммитов. Новые версии сверху.

| Дата | Что изменилось | Что это значит для вас |
|---|---|---|
| **2026-08** | Большой рефакторинг: пресеты убраны (ползунок скорости 0–100%), индикация ошибок через статусный LED, упрощена кнопка нагревателя; **формула нагрева с температурной компенсацией**: `мощность% × скорость / 10000 × (2 − 0,05·T)`; добавлен сенсор `heat_current`; убран сброс Wi-Fi зажатием кнопки подсветки | Нагрев автоматически снижается с ростом температуры (при +40 °C — до нуля); ложные срабатывания защиты побеждены; при смене сети ничего нажимать не нужно — плата сама поднимает точку доступа (~через минуту) |
| **2026-05-19** | Переход с Arduino на **ESP-IDF**; `name_add_mac_suffix: true`; включён `min_power: 0.22` (баг ESPHome починен) | Мониторинг оборотов заработал стабильно; несколько бризеров не конфликтуют; минимальная скорость реально ниже (50% «старых» ≈ 30% «новых») |
| **2025-11-04** | «Fix button sensor»: инверсию сенсорной кнопки нагревателя вынесли в флаг [`TK2_mode`](06-firmware.md#tk2) | Разные партии сенсоров (TTP223) работают с разной полярностью: платы до 10.2025 — `true`, после — `false` |
| **2025-08-30** | Починен датчик температуры: `attenuation: auto`, новая калибровка (20 °C / 12.5 кОм) | Показания стали адекватными |
| **2025-07-15/16** | Реакция на инцидент: сочетание captive portal + Improv по Bluetooth перезагружало устройство — партию плат перешивали через TTL. Выложены бинарники, добавлены кнопка **safe mode** и web-gui | Аварийное восстановление без разборки |
| **2025-07-04** | Добавлены переключатель пищалки (`oneair_buzzer`) и BLE Improv | Пищалку стало можно выключить из HA/веба без перепрошивки |
| **2025-07-01** | Начальная публичная версия. Формула нагрева — только от скорости (`мощность × скорость`), `min_power` закомментирован (баг ESPHome с min/max в PWM), кнопки — пресеты Low/Medium/High | Самая первая версия; всё, что выше в таблице, — улучшения относительно неё |

## Как понять, какая версия у вас

Точная версия в устройстве не хранится в явном виде. Ориентиры:

- Пресеты «низкая/средняя/высокая» в интерфейсе → версия до 2026-08
- Красный мигающий «периодически без причин» → вероятно до 2026-08 (побеждено)
- Проценты скоростей «стали другими» → граница 2026-05 (min_power)
- Несколько бризеров конфликтуют именами → до 2026-05

Сомневаетесь — просто [обновитесь](06-firmware.md#ota) до актуальной.
